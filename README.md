# Hana Bassam — Portfolio

A responsive personal portfolio website for Hana Bassam.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout

## Before publishing
1. Replace the LinkedIn `href="#"` with your real LinkedIn URL.
2. Replace the GitHub `href="#"` with your real GitHub URL.
3. Replace `YOUR_EMAIL@example.com` with your email.
4. Add links to your real project repositories.
5. Add your AWS Cloud Foundations certificate and additional projects when desired.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Create a GitHub repository, upload `index.html` and `style.css`, then enable GitHub Pages from the repository settings.
